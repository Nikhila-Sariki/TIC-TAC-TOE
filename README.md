# TIC-TAC-TOE
A basic TIC-TAC-TOE application where the user and computer play with each other
## The Basic Version
In this version, the computer is not considered intelligent, it plays in a random manner choosing random options
## The Advanced Version
In this version, the computer is smart and chooses it's moves always aiming for victory
## Language 
This code is written in Python
## Files
- tic_tac_toe.py  TIC-TAC-TOE  the basic version
- tic_tac_toe.py  TIC-TAC-TOE  the advanced version
- Win detecting algorithm.py  code which contains the function for choosing success-aiming moves
